# Bash Scripting

This directory documents my Bash scripting exercises, challenges and practical projects completed throughout my CoderCo DevOps programme.

My focus is on developing scripting and automation skills through practical exercises, troubleshooting and progressively more complex challenges.

## Repository Structure

**Scripts**

Individual exercises covering Bash fundamentals, including:

- Variables and parameters
- Conditional statements
- Loops
- Functions
- File operations
- Error handling
- Environment variables

Each exercise contains its original script and a README explaining its purpose, the concepts demonstrated and how to execute it.

**Challenges**

Practical scripting challenges that combine multiple Bash concepts to solve specific problems.

Each challenge includes its requirements, implementation, execution instructions and key takeaways.


## Objectives

- Develop confidence writing Bash scripts.
- Understand fundamental scripting concepts.
- Practise Linux automation and troubleshooting.
- Apply Git and GitHub version control.
- Build towards practical DevOps automation projects.

## Progress

This repository will be updated as I revisit earlier exercises and complete additional challenges throughout the programme.
