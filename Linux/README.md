# Linux | CoderCo DevOps Bootcamp

## Overview

This directory documents my Linux learning journey as part of the CoderCo DevOps Bootcamp.

Linux provides the foundation for many of the technologies used in DevOps, including containers, cloud infrastructure, automation and CI/CD pipelines.

My objective is to develop practical Linux administration skills through hands-on exercises, command-line practice and the OverTheWire Bandit challenges.

All exercises are completed in my Linux learning environment and documented to demonstrate my understanding and technical progress.

---

## 1. Module Goals

By the end of this module, I aim to:

- Navigate the Linux file system confidently using the command line.
- Manage files, directories and Linux permissions.
- Understand process management and system monitoring.
- Use essential Linux utilities, including `grep`, `awk`, `sed` and `find`.
- Work with Linux users, groups and `sudo` privileges.
- Complete and document OverTheWire Bandit Levels 1–20.

---

## 2. Linux Learning Environment

My primary Linux learning environment is an Ubuntu Server virtual machine running on Proxmox.

I access the VM remotely using SSH and Visual Studio Code Remote-SSH, allowing me to practise Linux commands, develop scripts and manage my GitHub repository directly from the terminal.

This environment provides a dedicated space to experiment with Linux administration and DevOps fundamentals.

---

## 3. Core Linux Exercises

The [Exercises](Exercises/) directory contains practical exercises covering the fundamental skills introduced throughout the Linux module.

| Exercise | Description |
|---|---|
| Environment Setup | Verify the Linux environment and practise basic system identification commands. |
| File System Navigation | Navigate directories, manage files and explore the Linux file system. |
| Permissions and Ownership | Practise managing file permissions and ownership using Linux commands. |
| Process Management | Monitor processes, manage background jobs and terminate processes. |
| Text Processing | Practise searching, filtering and manipulating text using Linux command-line utilities. |

Each exercise will include documentation explaining the commands used, their purpose and what I learned.

---

## 4. OverTheWire Bandit

The [Bandit](Bandit/) directory documents my progress through the OverTheWire Bandit challenges.

Bandit is a command-line learning game designed to develop Linux problem-solving skills through practical challenges.

My goal is to complete and document Levels 1–20.

For each level, I will document:

- The challenge requirements.
- The commands used to solve the challenge.
- An explanation of how the commands work.
- Any difficulties encountered.
- Key learning outcomes.
- Relevant terminal screenshots.

**Challenge:** [OverTheWire Bandit](https://overthewire.org/wargames/bandit/)

---

## 5. Key Learning Outcomes

Throughout this module, I aim to strengthen my understanding of:

1. Linux file system navigation and directory management.
2. File permissions, ownership and user administration.
3. Process management and Linux system monitoring.
4. Text processing, pipelines and command-line utilities.
5. Troubleshooting and problem-solving using the Linux terminal.

These skills will support my progression into more advanced DevOps technologies.

---

## 6. Why Linux Matters in DevOps

Linux is widely used across cloud infrastructure, servers, container platforms and automation environments.

Understanding Linux is essential for working with technologies such as Docker, Kubernetes, AWS and CI/CD pipelines.

Developing strong Linux administration skills will allow me to troubleshoot infrastructure, automate repetitive tasks and better understand the environments in which applications are deployed.
