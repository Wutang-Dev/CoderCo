# OverTheWire Bandit | CoderCo DevOps Bootcamp

## Overview

This directory documents my progress through [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) as part of the CoderCo DevOps Bootcamp.

Bandit is a Linux command-line wargame designed to develop practical problem-solving skills through progressively challenging levels.

My goal is to complete and document Levels 0–20, strengthening my understanding of Linux commands, file permissions, text processing, SSH and troubleshooting.

Each level will include:

- Challenge objectives
- Commands used and explanations
- Password discovered
- Challenges encountered and lessons learned

All solutions will reflect my original work, providing a record of my Linux learning journey and practical experience with essential DevOps fundamentals.
