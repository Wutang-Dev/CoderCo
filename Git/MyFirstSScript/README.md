# My First Bash Script

## Overview

My first Bash scripting exercise as part of my CoderCo DevOps learning journey.

This exercise focuses on understanding Bash variables, displaying output and executing scripts in Linux.

## What the Script Does

The script stores the message "Hello, World!" inside a variable named `greeting`.

It then uses the `echo` command to display the value of that variable in the terminal.

## Concepts Practised

- Bash shebang (`#!/bin/bash`)
- Creating and assigning variables
- Accessing variables using `$`
- Displaying output using `echo`
- Setting executable permissions with `chmod`
- Executing Bash scripts

## Running the Script

Give the script execution permissions:

```bash
chmod +x my-first.script.sh
```

Execute the script:

```bash
./my-first.script.sh
```

Expected output:

```text
Hello, World!
```

## Key Takeaway

This exercise helped me understand how Bash variables store values and how those values can be accessed within a script.

I also practised Linux file permissions and executing scripts directly from the terminal.
