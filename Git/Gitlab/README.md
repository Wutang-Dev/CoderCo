# Git Practice Lab

This directory is my hands-on environment for practising Git as part of my CoderCo DevOps learning.

The purpose of this lab is to move beyond simply using `git add`, `git commit`, and `git push` and develop a better understanding of how Git works in real development workflows.

## Topics Practised

- Creating and switching branches
- Staging and committing changes
- Pushing branches to remote repositories
- Merging branches into `main`
- Fast-forward merges
- Deleting local and remote branches
- Resolving merge conflicts
- Rebasing branches
- Cherry-picking commits
- Viewing and understanding Git history
- Using `.gitignore`
- Working with pre-commit hooks

## Approach

I use this directory as a safe environment where I can create files, branches, commits and intentional problems without affecting my main projects.

Exercises and experiments will be added as I continue through the Git module of the CoderCo bootcamp.

The goal is to understand not only which Git commands to use, but what each command is doing and why.
