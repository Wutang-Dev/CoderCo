About This Project

This project was developed as part of the CoderCo Docker module to demonstrate containerisation, networking and load balancing.

Technologies Used

Python Flask | Redis | Docker | NGINX | Docker Compose

Infrastructure

NGINX acts as a reverse proxy and load balancer, distributing requests across three Flask containers.

Redis stores the visitor count using persistent Docker volume storage.
