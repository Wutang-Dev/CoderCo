## Troubleshooting methodology

For each incident, I follow a consistent approach:

1. **Identify:** Understand the symptoms and error messages.
2. **Investigate:** Collect information using relevant diagnostic commands.
3. **Diagnose:** Establish the underlying cause.
4. **Resolve:** Apply and document the solution.
5. **Verify:** Confirm the issue has been resolved.
6. **Reflect:** Record lessons learned and preventative measures.
