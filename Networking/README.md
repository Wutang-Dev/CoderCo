# Networking

This directory documents my networking studies and practical work completed as part of the CoderCo DevOps bootcamp.

The module focuses on understanding how devices communicate across networks, how traffic moves between systems, and how core networking services such as DNS, routing and firewalls support modern infrastructure.

The practical work builds towards deploying a web server in AWS and making it accessible through a custom domain using DNS.

---

## Module Goals

By completing this module, I aim to develop a practical understanding of:

- How data moves across a network
- The OSI and TCP/IP networking models
- IPv4 addressing and subnetting
- Public and private IP addressing
- MAC addresses and ARP
- DNS and domain name resolution
- DHCP and automatic network configuration
- Routing and default gateways
- TCP and UDP
- Common network ports and protocols
- Firewalls and network security
- HTTP and web traffic
- Basic network troubleshooting
- Cloud networking concepts using AWS

---

## Practical Assignment

The final networking assignment brings several of these concepts together by deploying a web server and making it accessible through a custom domain.

The project will include:

- Deploying NGINX locally on an Ubuntu Server VM
- Testing connectivity across my local network
- Deploying an AWS EC2 instance
- Installing and configuring NGINX
- Configuring the required AWS security group rules
- Creating a DNS A record pointing to the EC2 public IPv4 address
- Testing HTTP connectivity through the custom domain
- Documenting the deployment and troubleshooting process
